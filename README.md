# CareerForge OS

AI-Powered Career Engine & Application Workspace.

## Overview

CareerForge OS is a local-first platform designed to streamline job search tracking, resume customization, ATS score optimization, and application management.

## Getting Started

### Prerequisites
- Python 3.11+
- Node.js 20+

### Setup

```bash
# Create and activate virtual environment (optional if using start.bat)
python -m venv .venv
.venv\Scripts\activate

# Install dependencies in editable mode
pip install -e .[dev]
```

### Running Locally

```bash
# Launch the application (starts backend and serves built frontend)
start.bat
```
